# 🎧 DJ Audio Application (C++ / JUCE)

This project is a simple DJ-style audio application built using C++ and the JUCE
framework. It provides a basic two-deck interface that allows users to load,
play, and manipulate audio tracks similar to a DJ mixing setup.


## 🎮 Features

- Load audio files from the local device
- Two independent audio tracks (decks)
- Play / stop audio playback
- Volume control for each track
- Playback speed adjustment
- Basic frequency filtering


## 🖥 User Interface

- Built using the JUCE UI framework
- Slider-based controls for volume, speed, and filter
- Simple and intuitive layout for real-time interaction


## 🛠 Technologies

- C++
- JUCE Framework
- Projucer (for project configuration and build setup)


## ▶️ How to Run

1. Download and install **Projucer**
2. Open the `.jucer` project file in Projucer
3. Configure the exporter for your platform (e.g. Xcode or Visual Studio)
4. Build and run the project from the generated IDE project


## 📌 Notes

This project focuses on demonstrating basic audio playback and manipulation
using JUCE, and is intended as a learning project rather than a full commercial
DJ application.
